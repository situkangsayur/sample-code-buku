# Algoritma 101

Contoh kode buku *Algoritma 101* (Hendri Karisma, STMIK Tazkia). Setiap folder `babNN-*` berisi
versi lengkap potongan kode di bab yang sama: berkas Python (`python3 nama.py` menjalankan uji)
dan satu crate Rust di `rust/` (`cargo test`, `cargo run --bin nama`).

Kebutuhan: Python 3.12 atau lebih baru, Rust 1.84 atau lebih baru (Bab 7 memakai `u64::isqrt`).
