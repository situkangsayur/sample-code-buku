# Bab 9: Dari Pseudocode ke Python

Kode lengkap Bab 9 buku *Algoritma 101*. Semua berkas mandiri dan menjalankan uji `assert` sendiri.

| File | Isi | Kaitan di buku |
|---|---|---|
| `padanan.py` | maksimum, jumlah deret, FPB, faktorial, repeat-until dengan `while True`, `match`, `continue` | Algoritma 9.1, Kode 9.2–9.3, Tabel 9.1–9.2 |
| `list_dan_fungsi.py` | list, slice, aliasing, list 2D, parameter bawaan, module | Kode 9.7 |
| `bilangan.py` | `int` tanpa batas, `/` dan `//`, `0.1 + 0.2`, `math.isclose`, batas konversi 4300 digit | Kode 9.8–9.9 |

Cara menjalankan (Python 3.12 atau lebih baru):

```
python3 padanan.py
python3 list_dan_fungsi.py
python3 bilangan.py
```
